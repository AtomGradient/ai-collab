# Phase 0 machine-readable contracts

> 状态：Host logical IPC v1、participant driver suite v2、Scenario/Participant state v1、Collaboration Policy/reliable-delivery v1、Workspace/Environment v1 与 gate registry v2 已 review/进入 `main`；permission/high-risk confirmation v1 contract implementation in progress

- [host_ipc_v1.schema.json](host_ipc_v1.schema.json)：App/CLI/TUI client ↔ Host 的 transport-neutral JSON Schema。固定 version handshake、typed request/reply、target/fence、async progress/cancel、operation descriptor meta-contract 与 structured error/mutation semantics。
- `scripts/validate_ai_collab_ipc_contract.py`：只读 conformance validator 与受限 JSON Schema instance validator；不启动 Host、不连接 XPC、不读取 Harness state。
- [participant_drivers_v2.schema.json](participant_drivers_v2.schema.json)：Runtime/Presentation driver interface、capability descriptor、composed registry、generation-scoped launch/model/process/presentation binding 的供应商中立 contract。`explicit_recreate` 是 required baseline；vendor session identity 与 `exact_resume` 仅为显式 optional capability。

对声明`exact_resume`的fresh interactive runtime，nullable `vendor_session_identity_sha256`还表达input-ready但首个真实vendor turn尚未物化的pending状态；它不授权`--last`、picker、role/cwd或private-store fallback。driver必须在首次真实turn后通过声明的lifecycle surface静默绑定，并在normal Close/Stop前固化；已有binding的Resume仍必须指定并核对exact identity。
- `scripts/validate_ai_collab_driver_contract.py`：只读 contract/registry/value conformance validator；校验 capability 组合、Host IPC error namespace 隔离、ready/create ACK exact binding，以及 TUI one-window/headless no-window composition，不启动 driver、不读取 vendor store 或 Harness state。
- [scenario_participant_state_v1.schema.json](scenario_participant_state_v1.schema.json)：Scenario/Participant desired/observed state、generation/revision、lifecycle operation、CAS fence 与 operation journal contract；固定 dynamic lifecycle、compound replace、detach-before-cleanup 和 participant fault-isolation 语义，并通过 `runtime_binding_id` 引用 driver suite v2。
- `scripts/validate_ai_collab_state_contract.py`：只读 contract/state/transition/operation/journal/aggregate validator；不实现 Host storage/transaction，不执行 driver/adapter 外部动作。
- [collaboration_policy_delivery_v1.schema.json](collaboration_policy_delivery_v1.schema.json)：供应商/项目中立的 ordered Collaboration Policy、精确 route decision、durable enqueue acceptance、policy/retry snapshot、delivery journal、delivery ACK 与 consumption ACK contract；canonical 状态仅为 `queued → delivery_attempted → delivered → consumed`，Host restart恢复所有非终态且不得重复注入已 delivered消息。
- `scripts/validate_ai_collab_policy_delivery_contract.py`：只读 contract/policy/route/enqueue/delivery transition/restart-resume validator；依赖 C/D 固定的 IPC 与 participant binding，不调用 vendor API、不投递真实消息、不读取 mailbox 或 Harness state。
- [workspace_environment_v1.schema.json](workspace_environment_v1.schema.json)：project-neutral Workspace/Environment adapter descriptor、immutable plan、operation journal、ready receipt 与 drift observation contract；项目特定的 SCM/environment payload 只以 schema/payload digest 接入。
- [gate_registry_v2.schema.json](gate_registry_v2.schema.json)：composed registry 的只读 snapshot、status-free gate projection 与 workflow phase projection contract；fingerprint 继续使用完整 YAML source SHA-256，canonical/per-gate digest 不替代 evidence identity。
- `scripts/validate_ai_collab_workspace_environment_contract.py`：只读 generic + EdgeStudio integration validator；把 plan/receipt 精确 join 到 root descriptor/repo manifest，校验 required/unmanaged boundary、exact revision、logical ref、隔离写入、environment binding、append-only journal、atomic publish/CAS 与 status drift，不观察本机 inventory、不 provision。
- [permission_confirmation_v1.schema.json](permission_confirmation_v1.schema.json)：供应商/平台中立的 permission matrix/snapshot 与 explicit confirmation challenge/decision/authorization/consumption contract；high-risk/destructive 只允许 exact single-use，bounded scope 仅用于非 high-risk operation。
- `scripts/validate_ai_collab_permission_confirmation_contract.py`：只读 contract/matrix/permission/confirmation chain validator；精确 join Host IPC operation descriptor，重验 permission freshness/subject、target/fence、scope membership 与 replay/expiry，不探测系统权限、不显示 confirmation UI、不执行 mutation。

当前 contracts 已包含 Scenario/Participant lifecycle、Policy/routing/reliable-delivery、Workspace/Environment plan/receipt、composed registry 的结构加载/只读 projection，以及 permission/high-risk confirmation 的逻辑语义，但不包含具体 Host storage/transaction/transport、真实 adapter execution、gate current-status/freshness engine、project policy/operation/permission population、系统 permission probe/prompt 或 trusted App confirmation UI，也不注册真实 vendor/platform driver。后续 implementation 通过 allowlisted operation descriptor 的 request/result schema digest 组合，Host 在 durable 或 external mutation 前完成 registry、schema、capability、target、generation、current permission 与 confirmation 检查。macOS XPC 是 platform binding，不是产品核心 schema；Phase -1 的单一 `status` probe 只证明 transport feasibility，不是 production operation registry。
